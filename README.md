## 🇷🇺 Разработка электроники и встроенных систем

Инженер-разработчик полного цикла (схемотехника, трассировка печатных плат, программирование микроконтроллеров) [•]. Сочетаю проектирование устройств с практическим опытом работы технологом на электронном производстве [•]. 

Специализируюсь на проектировании устройств с учетом стандартов DFM (Design for Manufacturing) [•]. Это позволяет минимизировать количество итераций плат, оптимизировать BOM-листы под сборочные линии и снизить процент брака при серийном монтаже [•].

### 🛠 Технологический стек и инструменты
* **Схемотехника и PCB (Hardware):** Altium Designer, KiCad, LTspice (симуляция цепей) [•]. Проектирование 2-слойных и многослойных плат, трассировка с учетом требований ЭМС, управление теплоотводом, генерация производственных пакетов (Gerber, Excellon, BOM, Pick-and-Place) [•].
* **Программирование (Firmware):** чистый язык Си (ISO/IEC 9899:2011), Microchip Studio, VS Code, GCC Toolchain [•]. Разработка на уровне регистров (Bare-metal), написание драйверов периферии, реализация алгоритмов цифровой фильтрации и ПИД-регулирования [•].
* **Архитектуры МК:** Microchip AVR (семейство ATmega), STM32 (ядра ARM Cortex-M) [•].
* **Тестирование и верификация:** Proteus VSM (виртуальное прототипирование, инжекция ошибок), работа с осциллографами и логическими анализаторами [•].

## 🇬🇧 Hardware & Embedded Systems Development

Full-cycle hardware and embedded firmware engineer [•]. Combining electronic design with a solid background in manufacturing engineering [•]. Focused on DFM (Design for Manufacturing) optimization to minimize hardware revisions and ensure production-ready layouts [•].

### 🛠 Tech Stack & Tools
* **EDA & PCB Design:** Altium Designer, KiCad, LTspice. 2-layer & multi-layer board routing, EMC-aware layouts, thermal management, production file generation (Gerber, Excellon, BOM, Pick-and-Place) [•].
* **Embedded Firmware:** Pure C (ISO/IEC 9899:2011), Microchip Studio, VS Code, GCC Toolchain. Bare-metal register-level programming, peripheral drivers, digital filtering, and PID control loops [•].
* **MCU Architectures:** Microchip AVR (ATmega), STM32 (ARM Cortex-M cores) [•].
* **Verification:** Proteus VSM (virtual prototyping, fault injection testing), hardware debugging via oscilloscopes and logic analyzers [•].
